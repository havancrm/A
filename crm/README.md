# CRM ภาคสนาม (ต้นแบบ)

แอปสำหรับเซลล์ดูแลลูกค้านอกสถานที่ ใช้มือถือ ทำงานได้ทั้งออนไลน์และออฟไลน์ ไม่มีค่าใช้จ่าย

## วิธีเปิด

1. สร้างข้อมูลจากชีต A (ดูหัวข้อ "สร้างข้อมูล")
2. เปิดไฟล์ `crm/index.html` ในเบราว์เซอร์ (ไม่ต้องติดตั้งหรือเซิร์ฟเวอร์)
3. บนมือถือ คัดลอกโฟลเดอร์ `crm/` ทั้งหมดไปที่เครื่อง แล้วเปิดด้วยเบราว์เซอร์

## กติกาการจัดการข้อมูลที่ขาด

- ไม่มีเจ้าของ: แสดงป้าย "ไม่มีเจ้าของ" และอยู่ในตัวกรอง เซลล์กดมอบหมายได้เอง
- ไม่มีพิกัด: ใช้ที่อยู่ค้นหาในแผนที่แทน เซลล์จับพิกัดจากเครื่องได้ตอนอยู่หน้าร้าน
- ไม่มีรอบเยี่ยม: ใช้ค่าเริ่มต้นจากหน้าตั้งค่า (ตอนนี้ 30 วัน) ซึ่งเป็นค่าที่ผมตั้งไว้ชั่วคราว ต้องให้ผู้จัดการยืนยัน
- ไม่มีเบอร์: ปุ่มโทรถูกปิด เซลล์เพิ่มเบอร์ได้ทันที
- ไม่มีเงื่อนไขชำระ: ใช้ "เงินสด (ค่าเริ่มต้น)" แสดงให้เห็นว่าเป็นค่าเริ่มต้น

## สร้างข้อมูล

ข้อมูลลูกค้ามีเบอร์และที่อยู่ จึงไม่ถูกเก็บไว้ใน git (ดู `.gitignore`)

1. ส่งออกจากชีต A เป็น JSON ตามรูปแบบ Sheets `values` แล้วบันทึกไว้ที่
   - `crm/data/source/customers.json` (customers!A1:AD)
   - `crm/data/source/bills.json` (bills!A1:M)
   - `crm/data/source/bill_items.json` (bill_items!A1:G)
2. รัน `python3 crm/tools/build_data.py` จะได้ `crm/data/data.js`
3. เปิด `crm/index.html`

ตอนนี้ตารางสินค้า (products) ในต้นแบบมาจากรายการที่เคยขายในบิล (453 รายการ) ยังไม่รวมทั้ง 438 แถวจากชีต products จะเพิ่มในรอบถัดไป

## หลักการแก้ไขโค้ด

- ไฟล์เดียวคือ `index.html` ทุกการแก้ไขทำในไฟล์นี้โดยตรง ไม่สร้างสำเนาเวอร์ชันใหม่ข้างๆ
- ประวัติการเปลี่ยนแปลงอยู่ใน git ถ้าต้องย้อนกลับใช้ git ไม่ต้องเก็บไฟล์สำรองไว้เอง
- ข้อมูลที่เซลล์บันทึกเองอยู่ใน localStorage ของเบราว์เซอร์ ทุกการเรียกใช้ห่อด้วย try/catch จึงไม่ทำให้หน้าพังเมื่อเก็บข้อมูลไม่ได้
- ข้อมูลที่บันทึกเองแยกจากข้อมูลจากชีต ทำให้สร้าง `data.js` ใหม่ได้โดยไม่ทับงานของเซลล์
